# AgiBot X2 Ultra — Accesso ROS 2 via WiFi da WSL2

Questa documentazione spiega come collegarsi all'AgiBot X2 Ultra da un PC Windows tramite WSL2 e il WiFi del robot.

## Per gli studenti

Seguite esclusivamente [`computer_setup.md`](computer_setup.md) e svolgete i passaggi dal computer.

La configurazione del robot è già predisposta. Non accedete al robot per modificare file o configurazioni, non eseguite comandi sul robot e non riavviate i suoi servizi.

## Documentazione riservata ai manutentori

[`robot_setup.md`](robot_setup.md) descrive la configurazione lato robot ed è destinato esclusivamente ai manutentori autorizzati. Gli studenti non devono seguirlo.
